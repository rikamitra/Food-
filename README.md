# 🍽️ Responsive Restaurant & Food Delivery Web App

A responsive front-end web application built for a modern restaurant and food delivery service. Designed with clean layouts, smooth scrolling, and interactive UI elements to showcase menus, featured dishes, and mobile ordering.

## ✨ Key Features
- **Responsive Design:** Adapts seamlessly across desktop, tablet, and mobile screens.
- **Interactive Navigation & UI:** Smooth scroll behavior, active section highlighting, and mobile menu toggling powered by vanilla JavaScript.
- **Menu & Featured Dishes:** Dedicated showcase sections for signature plates, pricing, and food delivery highlights.
- **Mobile App Promotion:** Dedicated section highlighting mobile app availability and ordering convenience.
- **Service Highlights:** Clean visual breakdown of dining, quality food, and fast delivery offerings.

## 🛠️ Tech Stack
- **HTML5 (74.0%):** Semantic page structure and content layout (`index.html`).
- **CSS3 (18.1%):** Custom styling, flexbox/grid layouts, and responsive media queries (`style.css`).
- **JavaScript (7.9%):** DOM manipulation and interactive UI behavior (`script.js`).
